# thedailyletter — archive

Backup copy of thedailyletter.com's social and archive assets. Not linked to
the live site or any deploy — pure safekeeping in case the local machine
goes down.

- `Archive Screenshots/` — full-letter screenshots, one per published letter.
- `Social Posts/` — static PNG + animated GIF pairs used for Instagram/Facebook/X.

Source of truth for letter text itself lives in the main `thedailyletter` repo.
